# Семинар 5 — вариант 57: география и границы территорий

Ноутбук [Семинар_5_Вариант_57.ipynb](Семинар_5_Вариант_57.ipynb) загружает сведения напрямую из Wikidata через SPARQL. Ручные countries.csv и borders.csv остались только как архив предыдущей версии и в расчётах не участвуют. Краткие результаты, типы границ и три ошибки разобраны в [REPORT.md](REPORT.md).

## Запуск

Из папки topic-05 установите зависимости: python -m pip install numpy pandas requests rdflib matplotlib scikit-learn notebook nbclient nbformat. Для полного запуска выполните python run_seminar.py. Он выполнит ноутбук и построит рисунок графа. Нужен доступ к https://query.wikidata.org/sparql.

Ноутбук запрашивает связи P47 между объектами Wikidata, помеченными как sovereign state (P31=Q3624078), а также P36, P37, P38, P30. Для P47 он получает квалификаторы и пограничный объект P805, по источнику уточняет тип границы (суша, вода, точка), а также выводит связи стран по общему официальному языку и валюте. Все пять прямых отношений участвуют в train/validation/test; производные связи остаются в RDF-графе для анализа и визуализации. В results/ сохраняются JSON-ответы, SPARQL-запросы, Turtle-граф, таблицы разбиения и деталей границ, метрики, эмбеддинги и рисунки. Источник данных и ограничения описаны в SOURCES.md.

Скрипт [draw_geography_graph.py](draw_geography_graph.py) можно запустить отдельно после Run All в Jupyter: `python draw_geography_graph.py`. Он читает уже созданный `results/geography57.ttl` и сохраняет `results/graph_example.png`: показывает тип границы, QID пограничного объекта, свойства страны и связи по языку и валюте. Для другого центрального объекта укажите, например, `--center Q142`. Скрипт `run_seminar.py` вызывает отрисовку автоматически.

Для визуализации уже сохранённых эмбеддингов без повторного запроса к Wikidata выполните `python plot_embeddings.py`. Скрипт создаёт `results/embedding_projection.png` с PCA и t-SNE для структурных, TransE и DistMult векторов стран. Этот же рисунок строится в конце ноутбука.

## Просмотр связей страны онлайн

Откройте [wikidata_country_viewer.html](wikidata_country_viewer.html) в браузере и введите точное название страны или QID, например `Германия` или `Q183`. Страница запрашивает Wikidata Query Service только для выбранной страны и показывает соседей с типами и объектами границы, столицу, официальный язык, валюту, континент, страны с общими языками и валютами. Нужен доступ к интернету. Данные не сохраняются локально и весь граф заранее не загружается.
